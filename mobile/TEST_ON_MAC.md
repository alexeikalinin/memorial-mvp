# Первый запуск на Mac после обновления

Состояние 30.10.2026: клиент подготовлен к тестированию. Это ещё не подписанный релиз App Store/TestFlight. Проверены браузерный предпросмотр, общий API, кодовые сборки iOS/Android; запуск нативной сборки на устройстве остаётся обязательным.

1. Установите полный Xcode 26.4 или новее, откройте его, примите лицензию и установите iOS Simulator. Текущий Expo SDK 58 требует iOS 16.4+ (https://docs.expo.dev/versions/v58.0.0/).
2. В Xcode → Settings → Locations выберите установленный Xcode в Command Line Tools.
3. Используйте Node 24. В каталоге `mobile` выполните:

```sh
nvm use
npm ci
npm run ios:build
```

API по умолчанию — `https://api.vspomin.ai/api/v1`, сайт — `https://vspomin.ai`. Приложение использует тот же аккаунт и данные. Копировать секреты сервера не нужно. Для локального сервера используйте `.env.example`; localhost на телефоне указывает на сам телефон.

Для подключённого iPhone: `npm run ios:build -- --device`. Подпись выбирается в Xcode под вашим Apple ID. Удалённые сборки EAS, сертификаты и публикация в магазинах пока не настроены.

## Обязательная проверка устройства

- Вход email/Google, выход, повторный запуск и сохранение сессии.
- Создание страницы живого/умершего человека, даты, девичья фамилия.
- Создание/редактирование воспоминания, запись микрофона, отказ в разрешении и повторная попытка.
- Выбор фото/видео из библиотеки, воспроизведение аудио/видео, отмена выбора файла.
- Чат с источниками, озвучка, семейный поиск; проверка проводится на вашей тестовой странице, платные AI-запросы расходуют квоту.
- Модерация владельцем, доступ editor/viewer, запрет чужих закрытых материалов.
- QR/deep link, приглашение, открытие полного семейного дерева на сайте.
- Клавиатура, большой системный шрифт, поворот iPad, возврат из фона и временная потеря сети.

В первой версии родные показаны списком; полное интерактивное дерево и редактирование связей открываются на сайте. Приложение пока не повторяет все функции веб-редактора оформления/клонирования голоса. Для первоначального теста семейного архива текущего набора достаточно; для магазина нужны нативная проверка, подпись, политика конфиденциальности и материалы публикации.
