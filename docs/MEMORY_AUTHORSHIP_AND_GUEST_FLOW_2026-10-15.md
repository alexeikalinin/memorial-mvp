# Авторство и гостевое добавление воспоминаний — 15.10.2026

## Поведение
- Владелец видит «Автор воспоминания: …» в общем списке после одобрения. Имя не теряется при модерации.
- В приглашении появилось обязательное поле имени. Оно сохраняется отдельно от названия приглашения. Старые клиенты могут использовать label как fallback; публичная форма уже передавала имя. Пустое/пробельное имя отклоняется. Автор собственных записей определяется по текущему пользователю, не по присланному полю.
- Авторство передаётся в RAG при vector retrieval, SQL fallback и обзоре жизни. Оно доступно и независимой проверке ответа. Для «он ездил со мной» или «мы вместе» имя автора позволяет назвать спутника; один лишь факт авторства не подтверждает участия в событии. Явно названные другие участники имеют приоритет. Это правило разрешения местоимений, а не проверка личности автора.
- Гость без входа видит на вкладке приглашение поделиться историей и объяснение пользы. Тексты отсутствуют не только в интерфейсе, но и в anonymous API detail/memories/timeline (пустые массивы). Проверяется действительная авторизация без DEBUG owner shortcut. Вошедшим пользователям публичный approved archive доступен по прежним правилам; pending остаётся у владельца. Timeline теперь также исключает pending.
- Ответ чата без подтверждённых источников имеет suggest_memory=true. Интерфейс предлагает поделиться историей и предупреждает об одобрении владельцем. Кнопка открывает публичную форму, форму приглашения либо вкладку владельца с открытым редактором. Ошибки сервиса не выдаются за отсутствие воспоминания.
- Новые тексты добавлены RU/EN. Существующее временное скрытие переключателя EN сохранено. Таблицы БД и ключи/настройки production не менялись.
