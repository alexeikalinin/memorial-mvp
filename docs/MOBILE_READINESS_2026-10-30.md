# Проверка приложения и шапки, 30.10.2026

## Реализовано

- Производственный API по умолчанию вместо localhost; поиск по словам имени и девичьей фамилии.
- Пол/девичья фамилия, полные даты и проверка календаря/порядка дат при создании и редактировании. Отсутствующие даты можно очистить.
- Редактирование/удаление воспоминаний с подтверждением, обновление текущего раздела; индикаторы загрузки.
- Семейный поиск по умолчанию для имеющих доступ, ссылка на полное дерево, восстановление пароля через сайт. Отложенный отбор ответов для гостей скрыт, библиотека сохранена.
- Ограничение ширины на планшете. Зависимости обновлены совместимыми патчами Expo SDK 58.
- Веб: полные даты под портретом, имя без разрывов слов с подбором размера, оформление уступает место имени; увеличенная шапка. Безопасные сохранённые позиции декора сохраняются; даты закреплены под портретом.
- Дерево: CSS layout zoom вместо постоянного растрового слоя transform/translateZ; старые браузеры используют fallback. Фото ограничено исходным разрешением.

## Доказательства

Локальный изолированный сервер `mobile/integration/readiness_server.py`: вымышленные аккаунты, временная БД, синтетические фото/WAV/MP4 и заглушка AI. Производственные данные не изменялись, платные AI не вызывались.

`browser-smoke.cjs`: вход, создание страницы, воспоминания приложение → веб и обратно, загрузка фото → веб, ответ чата, выход и независимость веб-сессии, 320px без горизонтального переполнения.

`readiness-browser.cjs`: обзор, родные, история жизни, материалы, воспоминания; 320/390/430/768. Шапка owner/public: 320/390/430/768/1280, имя в пределах панели, даты центрированы под портретом, слова без внутренних переносов. Снимки: `artifacts/mobile-readiness-2026-10-30/` (локальные).

`readiness-actions.cjs`: невозможная дата отклонена, сохранение полных дат/фамилии, одобрение гостевого воспоминания, редактирование и отмена удаления, воспроизведение WAV/MP4 в RN Web, семейный флаг в реальном запросе к тестовому серверу.

## Оставшиеся ограничения

Нет полного Xcode на текущем Mac: нативная компиляция/установка, реальные системные разрешения, SecureStore, OAuth/QR на телефоне и работа в фоне не проверены. Expo export создаёт кодовые пакеты, а не подписанные IPA/APK. Установка и сценарии: `mobile/TEST_ON_MAC.md`.

Expo doctor: 20/20 после обновления. npm audit сообщает upstream advisories в инструментах Expo (zod 3/deepmerge); рекомендованный автоматический fix предлагает несовместимый откат Expo 51. Такой откат не применён; принудительная замена zod 3 на 4 требует отдельной проверки совместимости. Эти зависимости используются CLI/config, приложение напрямую их не использует.

Публикация веб-исправлений и итоговые проверки сборок отмечаются в SESSION_LOG.md / ROADMAP.md отдельно от этого локального отчёта.
