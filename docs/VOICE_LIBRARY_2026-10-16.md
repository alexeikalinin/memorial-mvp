# Сохранённые голоса и подготовка образцов — 16.10.2026

Новый клон сохраняется отдельным кандидатом. Первый голос выбирается автоматически; при наличии голоса последующие кандидаты не меняют активный и не удаляют его у провайдера. Владелец мемориала может просмотреть список, получить тестовую озвучку и выбрать сохранённый голос. Доступ к чужим версиям запрещён; старые voice_id лениво включаются в библиотеку. Удалённые до этого выпуска старые модели восстановить этим изменением нельзя.

Добавлена отдельная таблица memorial_voices; существующие колонки/данные не меняются. PostgreSQL создаёт таблицу через существующий Base.metadata.create_all при запуске. Поля: memorial, provider, remote ID, name, request_hash, state, timestamp, JSON-кэш коротких тестовых MP3. Cache ограничен фиксированным текстом, двумя разрешёнными TTS-моделями и RU/EN. API list не возвращает аудио, fingerprint или provider ID.

Повтор тех же файлов, включая переименование и перестановку, не создаёт новый клон. Хеш относится к точным байтам образцов после подготовки, не к акустической идентичности: другое кодирование/очистка считается другим материалом. UNIQUE memorial/request_hash предотвращает одинаковые параллельные попытки. PostgreSQL-блокировка мемориала сериализует резервирование разных наборов; pending не допускает следующий запуск. Failed/неопределённый результат не повторяется автоматически: требуется разбор причины/сверка с Fish администратором, чтобы не оплатить повторно потенциально выполненную операцию. Автоматического восстановления после падения процесса и UI удаления/импорта голосов в этой версии нет.

Короткая preview версии кэшируется на сервере по model/language; повторное прослушивание и переключение сохранённого кандидата не вызывают клонирование. Кэш не означает бесплатность первого синтеза или отсутствие расходов на обычные ответы. Сохранённые варианты продолжают занимать приватные слоты аккаунта Fish; лимит провайдера этой функцией не увеличивается. Общий каталог оплачиваемых пакетов и квоты не мигрированы.

Проверка Fish до вызова провайдера требует суммарную длительность <270с, проверяет аудиопоток и валидное конечное значение длительности, удаляет временные файлы при ошибке. Ошибка API про 270с заменена понятным текстом. Исходники не обрезаются автоматически.

Документация https://docs.fish.audio/api-reference/endpoint/model/create-model указывает в BODY train_mode только fast. full присутствует в RESPONSE enum и не является поддерживаемым режимом создания через этот API. TTS-модель/темп синтеза и режим создания клона — разные настройки; смена темпа не обучает более точный голос.
