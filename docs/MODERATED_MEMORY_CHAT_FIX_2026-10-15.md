# Воспоминание после модерации не находилось в чате

15.10.2026. Проверка локальной версии; конкретная production запись пользователя не читалась и не изменялась.

## Причина и воспроизведение
Одобрение сохраняло approved и пыталось поставить Celery-задачу, скрывая ошибку очереди. В чате резервное чтение SQL включалось только при полностью пустом контексте. Если векторный поиск возвращал старые записи (например, шахматы), новое воспоминание о рыбалке могло отсутствовать в контексте модели. Исключение поиска/embedding вопроса также обходило SQL fallback.

Новый regression-тест воспроизводит реальную цепочку HTTP: владелец создаёт приглашение; клиент без Authorization отправляет воспоминание о щуке на Нарочи; запись попадает в pending; чат до одобрения не получает текст; владелец одобряет при сломанном broker; запись видна в списке воспоминаний; повторное одобрение не дублирует задачу; чат после одобрения отвечает с источником новой записи.

Тест выполняет настоящий код RAG generation и проверки цитат/источников; ответы внешнего OpenAI и независимой проверки фактов подменены детерминированными ответами. Это не проверка качества реального LLM.

На исходном ai.py: 3 failed / 1 passed. Воспроизводятся stale index, недоступный поиск и недоступные embeddings; полностью пустой поиск уже обрабатывался.

## Исправление
- Векторные результаты дополняются одобренными воспоминаниями текущего мемориала из SQL, которых нет в результатах. Новые записи первыми; без дублей, дополнительный текст ограничен 18000 символами.
- При ошибке embedding вопроса/поиска используется SQL-контекст.
- Ошибка постановки индексации после одобрения теперь логируется. Долговременный мониторинг/retry очереди не добавлялись.
- Pending по-прежнему исключён; доступ к родственникам не расширялся; проверка подтверждённости фактов и источников сохранена.

Ограничения: большой архив не помещается полностью в контекст; векторная индексация по-прежнему нужна для полного поиска по старым записям. Дополнение контекста увеличивает объём входного текста модели в пределах установленного лимита. Внешний OpenAI, реальное второе устройство, production Redis/Qdrant и конкретная запись о рыбалке не проверялись. Изменения локальные, deployment не выполнялся.
