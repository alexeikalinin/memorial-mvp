# Проверка мобильных сценариев перед выпуском — 16.10.2026

## Исправления выпуска

- Каталог знаков памяти прокручивается отдельно от закреплённых кнопок. Высота и центр диалога учитывают visualViewport и safe area. Размер текста в полях на мобильных — 16px.
- После сохранения показывается подтверждение. Повторное действие обновляет вариант/подпись/комментарий без продления 24 часов. Последняя свеча выбирается первой; свечи посетителей также видны в ленте знаков.
- Идентификатор посетителя работает при отсутствии crypto.randomUUID и ограниченном хранилище (в последнем случае стабилен только в пределах вкладки).
- Запись выбирает поддерживаемый MIME, включая Safari MP4; имя файла соответствует реальному формату. Микрофон освобождается при уходе, отмене и ошибке создания рекордера.
- Распознавание: OpenAI API, модель whisper-1. Авторизация настоящим аккаунтом или действующим приглашением с add_memories. Проверяются мемориал, срок, язык, формат, пустой файл и размер до 25 MiB. Ограничение 5 запросов/минуту на источник. Ошибки провайдера возвращаются безопасным сообщением.
- Лендинг описывает реальные гостевые права; тарифы Plus $40/год, Family $80/год, Family Pro $140/год, Lifetime индивидуально подтверждены пользователем. Каталог в приложении вынесен в JSON, тест проверяет его соответствие обеим копиям лендинга.
- Новые платные тарифы по-прежнему принимают заявки без оплаты. Существующие платные подписки и прежние серверные квоты не мигрированы. Нельзя считать запуск оплаты новых пакетов завершённым: для этого нужны отдельные цены Stripe и реализация/проверка всех обещанных квот голоса, клонов и хранения.

## Выполнено автоматически

- 19 серверных тестов: знаки, обновление варианта без продления срока, истечение, права/журнал; гостевой лимит 5 и бесплатный аккаунт 15; приглашение для записи, MP4 и язык, несовпадающий/неизвестный токен, пустой/неподдерживаемый/слишком большой файл. Распознавание в этих тестах заменено тестовым ответом, реальный Whisper не вызван.
- 14 тестов frontend: формат MP4, освобождение микрофона, ограниченное хранилище, тарифный каталог и существующие проверки дерева/подсказок.
- Повторная сборка приложения и проверка критических ошибок Python прошли.
- Полный серверный прогон: 318 passed, 824 warnings, 122.83s.

## Обязательный ручной/браузерный прогон

- [ ] Safari/WebKit и Chromium: 320, 375, 390, 430, 768, 1024, 1440px; портрет/альбом, короткая высота и клавиатура. Нет горизонтальной прокрутки, обрезанных полей, перекрытия действий.
- [ ] Физический iPhone Safari с нижней панелью: открыть свечи/цветы, прокрутить, ввести имя/комментарий, сохранить; кнопки доступны при открытой клавиатуре. Эмуляция не заменяет аппаратную проверку.
- [ ] Все 10 свечей и 36 вариантов цветов выбираются; выбор виден до/после сохранения и перезагрузки. Повторный выбор обновляет оформление, не продлевает срок. Новый посетитель добавляет отдельный знак. Истёкшие исчезают, журнал владельца сохраняется.
- [ ] При ошибке сети показана ошибка, повторное нажатие возможно; во время отправки нет повторных запросов; после успеха понятное подтверждение.
- [ ] Гость по QR не получает архив ни через интерфейс, ни через API detail/memories/timeline; видит приглашение оставить историю. Снять мобильный скриншот.
- [ ] Пятый гостевой ответ доступен, шестой запрещён сервером; перезагрузка не сбрасывает счётчик. После входа новый бесплатный аккаунт имеет 15 ответов/месяц на аккаунт, 16-й запрещён; ошибки запроса не списывают ответ. Гостевой идентификатор браузера не является защитой от намеренной очистки хранилища.
- [ ] Чат без фактов отвечает честно и показывает CTA; CTA открывает форму с правильным мемориалом. Снять скриншот. Источник pending/rejected никогда не используется.
- [ ] Ссылка приглашения на другом устройстве без входа: текст+имя → pending → виден владельцу → одобрение → автор в общем списке → следующий ответ чата использует факт и корректного участника. Проверить отклонение, отзыв и истечение ссылки.
- [ ] Голос на Safari и Chromium: разрешить микрофон → запись → остановить → реальный Whisper → редактируемый текст → отправка → модерация → чат. Отказ микрофону, отмена/уход, тишина, сетевой сбой и ошибка провайдера не блокируют текстовый ввод.
- [ ] Отдельный реальный Whisper smoke с синтетической записью без частных данных. Проверить MP4/WebM и русский язык. Нынешние тесты с заглушкой не доказывают качество распознавания.
- [ ] Лендинг/тарифы на мобильном и ПК: одинаковые цены и лимиты, заявки доставляются, нет обещания немедленной активации оплаты. После отдельного запуска новых платных пакетов: Stripe test checkout/webhook/idempotency/cancel/renewal/expiry и все серверные квоты.
- [ ] После публикации повторить гостевой API smoke и загрузку новых assets; проверить backend/frontend deployment и CI.

## Результат браузерной проверки

Пользователь явно разрешил запуск 16.10; техническое ограничение снято. Отдельный Chromium и совместимый WebKit (Playwright1.59), без использования пользовательского браузера. Локальная SQLite с одноразовыми данными.

- Chromium/WebKit: 320×568, 375×667, 390×844, 430×932, 768×1024, 1024×768, 1440×900, 844×390. У кнопки сохранения проверены границы viewport и доступность через elementFromPoint. В обоих движках 390px свеча и цветы сохранены через настоящий API, видны после reload. Каталоги содержат10/36 вариантов; все варианты не сохранялись по отдельности. Слишком быстрый массовый тест достиг штатного лимита10/minute, после чего layout и сохранение проверены отдельно.
- При визуальной проверке найдены и исправлены переполнение CTA в сообщении и минимальная ширина поля ввода Safari. Итоговый скриншот сделан после завершения анимации; прежний ранний снимок с полупрозрачным текстом не служит доказательством дефекта цвета.
- Синтетическая речь подана через Web Audio в настоящий браузерный MediaRecorder → реальная multipart отправка с invite_token → редактируемый текст → pending в настоящем API → одобрение в UI владельца → автор Николай в общем списке → anonymous API=[] . Ответ транскрибации в этом браузерном сценарии перехвачен тестом. Системный fake microphone Chromium в окружении зависал на getUserMedia; аппаратный микрофон этим тестом не подтверждён.
- Отдельный реальный OpenAI whisper-1 вызов с синтетической MP4 без частных данных успешно вернул: “I remember fishing with Nicholas. We caught many fish that summer.” Это реальный тест провайдера, но не полный аппаратный сценарий iPhone.
- Реальный локальный API и UI: 5 гостевых ответов (с reload после второго), шестой401; новый зарегистрированный пользователь15 ответов, шестнадцатый402; usage=15. Тестовый архив пуст, поэтому внешняя генерация для лимитов не нужна.
- Дополнительно Home, создание мемориала, owner memories/media/chat, Pricing и собранный production landing проверены на320/375/390/430/768/1024/1440: без горизонтальной прокрутки и JS exceptions. Проверка ширины страниц не доказывает исполнение каждого элемента/оплаты/сторонней интеграции.
- Предыдущий выпуск уже подтвердил интеграционным тестом submit→pending→approve→chat retrieval, а реальным OpenAI на вымышленных данных — корректное использование Николая как участника. В этой партии full backend318 passed покрывает эти регрессии. Частная production история1494 во внешний AI повторно не отправлялась.
