# Восстановление проекта после обновления macOS

Исходники веба, сервера и мобильного приложения сохранены на GitHub: https://github.com/alexeikalinin/memorial-mvp

- Основной выпуск: `b1571697f54f224ab75fee13ac775cf79c12c555` в `main`.
- Точный снимок рабочей версии: `502c3be03acee1e83c900cce85f0962eed80a0f6`, ветка `codex/backup-before-macos-2026-10-21`.
- Мобильная разработка: `codex/mobile-app`; исходники находятся в `mobile/`.
- Состояние до мобильной разработки: тег `codex/mobile-start-2026-10-20`.

Для восстановления склонировать репозиторий в новую папку; существующую рабочую папку не сбрасывать. Установка сервера/веба: ENVIRONMENT.md, мобильного приложения: mobile/README.md. Для mobile используется Node 24 и отдельные зависимости; iOS требует Xcode. Перед установкой компонентов прочитать AGENTS.md и HANDOFF.md.

В Git намеренно отсутствуют `.env`, пароли, API-ключи, локальные базы, uploads, данные Qdrant, зависимости и тестовые скриншоты. Они не восстанавливаются простым клонированием. Настройки production хранятся на хостингах; данные действующего сервиса — в облачной PostgreSQL/Storage, векторы — на серверном volume. Обновление локального Mac не обновляет эти сервисы. Это не подтверждение резервных копий облачной БД или volume; для них нужен отдельный backup.

Сохранение кода в GitHub не является резервной копией всего Mac. Уникальные локальные файлы и данные следует отдельно скопировать на другой носитель или в облако.
