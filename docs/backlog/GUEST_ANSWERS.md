# Отложено: выбор ответов и озвучки для гостей

Статус: скрыто из интерфейса по просьбе владельца продукта, 29.10.2026.

Не показываем подборку владельцу, связанные кнопки озвученных ответов у воспоминаний, подборку гостям и подготовку по prepareGuests=1. Скрытый компонент не загружает список ответов. Обычный чат, озвучка сообщений, семейный поиск и архивные операции остаются доступны. Данные готовых ответов и серверные API не удаляются; существующие разрешения не меняются.

Центральный флаг: frontend/src/config/guestAnswers.js. Не включать до нового согласованного решения.

Перед возвратом в продукт:
- Спроектировать понятный выбор уже полученного ответа непосредственно в разговоре.
- Разделить выбор текста, записи голоса и создание нового дубля.
- Понятно показать владельцу, что именно увидит гость; предусмотреть предпросмотр.
- Продумать ответы с семейным контекстом и явный выбор разрешённых источников.
- Повторно проверить права, устаревание ответа, лимиты и стоимость озвучки.
- Согласовать прототип с владельцем продукта перед включением.
