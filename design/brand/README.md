# vspomin.ai — выбранная основа логотипа

Утверждено пользователем 2026-10-09. Этот каталог — актуальная основа для дальнейшей работы с логотипом. Прежний PDF от Claude удалён по запросу пользователя.

## Исходная композиция

`logo-master-reference.png`: прежний пиксельный профиль без женских волос, знак бесконечности, поднятое vspomin.ai с двумя огоньками и увеличенная подпись ВСПОМИНАЙ. Сохранять эту форму и направление при последующих доработках.

## Форматы и цвета

`logo-formats-01-06.png`:
- 01–03: горизонтальный логотип.
- 04–06: квадратная композиция — знак над названием и подписью.
- 01/04: тёплое золото на тёмном фоне.
- 02/05: бронзовое золото на светлом фоне.
- 03/06: одноцветная светлая версия на коричневом фоне.

`logo-formats-07-12.png`:
- 07–08: отдельный знак.
- 09–10: название и подпись без знака.
- 11–12: баннеры.

Палитра сайта: dark #080810, ivory #FAF8F5, bronze #8B5E3C, muted gold #C4A882. Основные пары: 01/04 для тёмного фона, 02/05 для светлого.

Это утверждённые растровые референсы семейства. Для точных экспортов SVG/PNG каждого формата сохранять единую геометрию из master-reference; AI-превью могут иметь небольшие различия. Название vspomin.ai и подпись ВСПОМИНАЙ обязательны в полном логотипе. Старые итерации в design-previews остаются архивом для возврата, а не актуальной основой.

Утверждённая основа применяется на сайте и в приложении: горизонтальные версии в шапке/hero/footer, квадратные на auth-страницах. Рабочие SVG находятся в frontend/src/assets и frontend/landing/images; один и тот же знак используется во всех вариантах.
